### [pendulum-theory](pendulum-theory.md)
Channels saturate on a cycle: texting 2018 (2–3K texts/deal), direct mail 2021 (3K mailers/deal), PPC 2022, PPL 2023, cold calling back 2024. Defense = sequential marketing: cold call always leads, cheap touches layer under expensive, never replaced. Touch costs: SMS $0.01, calls $0.03–0.06, mail $0.50–0.75, deep prospecting $1.50–4.00, door knocking $25–50 (2,500x text-to-knock gap). Start with two channels (text + call). Nate Beekman: $40K/mo PPC, CPL tripled, rebuilt lean on outbound.
Worth opening for: the year-by-year channel timeline, touch-cost ladder, Do/Not-This channel list.

### [phase-1-operator](phase-1-operator.md)
One county, one list, flow live, nothing delegated. Bands: Elite <10, Strong 10–35, Volume >35. Starter lists: Judgments 6.2, Pre-foreclosure Final Judgment 9.4, Negative Equity 10.9, Estate Sales 12.4, Pre-Probate/Deceased 14.8, AI 90+ ~22. Teaching buy box: $100–700K, SFR off-MLS, 30%+ or unknown equity. Run modes: you dial ($0.03–0.06/call), a caller ($750–1,000/mo, 150 dials/day), or mail-only. Sensitive lists: mail family immediately, no calls until 3 months after filing, never cold text; only ~30% of deceased owners ever file probate. First hire = data manager $500–700/mo with 3–6 months banked.
Worth opening for: the six-move standup checklist, fast-cycle (SiftMap) vs slow-cycle (FTM) dual engine, the 4 graduation gates.

### [phase-2-delegator](phase-2-delegator.md)
Data + admin off your plate (Data Manager $500–700/mo); phones stay yours. 4 full attempts per record (every number + voicemail + personalized text + manual counter), then mail. Daily order: follow-ups/rehash → attempt-3 → attempt-2 → attempt-1 → fresh last; the no-number skip-traced list gets mail FIRST. Handoff math: 150 dials/day, 75–100 correct-number not-interesteds ≈ 1 deal inside 12 months. Obituary rules restated; obituary reaches the 70% who never file probate.
Worth opening for: the magazine-feed call order, the exact "one full attempt" definition, Kasim ($100K+ on a W-2) and Josh ($60K rehashed liens) cases.

### [phase-3-manager](phase-3-manager.md)
Phones handed off; Replacement Ladder = Admin → Marketing → Sales → Leadership, never skip a rung. Seats: Data Manager $500–700/mo, Caller $750–1,000/mo, Lead Manager $1,500–3,000/mo, Closer $2,000 + 3–10%. Money Gate: 3–6 months of seat cost banked (caller = $2,250–6,000; lead manager = $4,500–18,000). Ratios: 2 callers per lead manager; 150-dial floor, two weeks under = coach or replace. Build statuses/tasks/boards/intake before the first interview; the trend is the full-cycle seller (one seat, zero handoffs).
Worth opening for: pre-hire system checklist, fixed hiring order with costs, the 3 graduation tests.

### [phase-4-owner](phase-4-owner.md)
Leadership hires: Sales Manager $5–6K + 2–5% override, Ops Manager $5–7K + bonus. Deep-prospect entry (any one): 4 attempts exhausted, return mail, vacant at both addresses, no numbers left — nothing archived; $1.50–4.00/record, one $20/mo Claude Pro replaces 2 full-time VAs. Obituary motion: ~30% file probate, pre-probate/deceased = 14.8 doors per deal, mail-now/no-calls-3-months. Foreclosure knocking: start auction −45 days, stop dialing at −3 days. Health metric = fully loaded cost per deal; expand on banked profit only.
Worth opening for: deep-prospect entry conditions, the knock timeline, the four-pillar audit loop, Quintin ($458K/7mo) / Mara ($200K on <$2K mail) / Brian cases.

### [first-to-market-data](first-to-market-data.md)
County-sourced distress records before any platform: $500–$2,000 per contract once built, but a 25–35 day build and 4–7 month sales cycle (~66 doors per deal aggregate, range 50–75). Six sources with office/format/difficulty/cost cards: probate (hard), tax sale/delinquent, foreclosure, pre-foreclosure, code violations (easy; FOIA ~10 business days, $5–25), evictions. Knox foreclosure: median notice-to-auction 34 days, market Days 1–30, 38% deceased-owner rate; 22–38% of all distress lists have deceased owners. Courthouse runners: TaskRabbit ~$20/hr, $40–80/trip covers 2–3 list types. Probate missing-address: manual 20–45 min/record vs Probate Property Finder skill 2–5 min, 50–100/day. Not-interested cadences: Probate 45 days, Foreclosure 15, General 90; 20–30% of deals come from not-interested follow-up.
Worth opening for: per-source cards, county difficulty tiers, the runner playbook, FTM County Data + Probate Property Finder skill links.

### [market-finder-workflow](market-finder-workflow.md)
4-phase drill-down (state → county → ZIP → neighborhood) on 4 metrics: median sales price, DOM, median home value, investor transaction volume. Rules: $375K national anchor, <3 months supply, the 60% price range (MN example $200K–$600K). Knox worked example: $352,500 median value, 91 monthly investor transactions (546/6mo, 20 active ZIPs), DOM 57–67, 3.9 months supply; top 6 ZIPs hold 328 of 546 transactions (60%); 37914 spread −22.3%; Lonsdale 35-day DOM / −36.2% spread. Skill produces the 7-tab report in 10–15 min vs 45–90 min manual.
Worth opening for: the 12-indicator county scorecard, top-10 ZIP/neighborhood tables, exit-strategy-by-segment table (wholesale $150K–$350K), ZIP-count sizing rule (1–2 deals/mo = 5–10 ZIPs), skill link.

### [sold-properties-analysis](sold-properties-analysis.md)
