### [niche-sequential-marketing](niche-sequential-marketing.md)

Two counters drive everything: `predictivecall_attempts` (dialer-written) and `directmail_attempts` + last-mailed date. Cadence: 27 touches in 72 hours — 3 call attempts (every number + voicemail + varied text each day) while Mail 01 (handwritten letter, ~$1.75, forever stamp, 1–3 day delivery) triggers Day 1 with no call prerequisite. Cost ladder: call $0.03–0.06, SMS $0.01, mail $0.50–2.00, deep prospecting $1.50–4.00. Six call-stage presets per folder (00 Needs Skipped → 05 Call Attempt 3) and a 6-piece mail rotation (letter → postcard → soft-offer check, repeat; month spacing automatic; piece 6 = exit). Universal suppression stack (6 exclusions incl. sub-20% equity, the 15 dead neighborhoods, Not Single Family, Mail Only on call presets). Reactivation timers: foreclosure-to-auction 15 days, probate 45, other FTM 90, Tier 2 45; 20–30% of platform deals come from not-interested follow-ups. Trestle scoring first cuts trash numbers ~50%; click-to-dial (smrtPhone) for niche, never a power dialer. External mail tracked via "DM MM/YYYY" tags + manual attempt increments; "Return Mail" tag feeds Deep Prospecting.

### [phone-scoring-trestle](phone-scoring-trestle.md)
The 2,000-record Trestle study behind the 5-tier system. Blind dialing = 2–3% connect rate, ~50% dead numbers, $2.25–4.50/day/caller wasted ($50–100/mo); scoring first → 9.5% connect (Joshua English split test, 4.75x). Tier data: Dial First 81–100 (881 phones, 43.4%, 30.3% correct / 1.9% dead), Dial Second 61–80 (99, 11.1%/11.1%), Dial Third 41–60 (102, 8.8%/12.7%), Dial Fourth 21–40 (671, 1.0%/34.6%), Drop 0–20 (275, 0.7%/33.0%). Dial First + Second = 48.3% of phones but 92% of correct numbers; Fourth + Drop = 46.7% of phones with 82% of dead. Distribution is bimodal (clusters at 30 and 100); 93.6% of Correct phones score ≥70, 88.4% of Dead score ≤30. Status-score anchors: CORRECT 95.3 mean, WRONG 78.2 (active line, wrong person — deep-prospecting signal), DEAD 31.8. Line types: Mobile avg 80.8, FixedVOIP 47.0, NonFixedVOIP 46.5, Landline 30.2; 24% of DataSift "Landlines" (187 of 776) are actually VOIP and textable. Cost ~$0.015/number. Three protection layers: Trestle (score the numbers you dial), Free Caller Registry (freecallerregistry.com, free, re-register every 3 months), Number Verifier (app.numberverifier.com — real devices on AT&T/T-Mobile/Verizon call your caller IDs daily; one carrier red 2+ days = remediate and cut dials; rotation rule: 400 dials/day on one number gets flagged, split across four usually doesn't). Skills: Claude Phone Validator (automates Trestle scoring + tags, Drive link) and Caller Reputation Monitor (reads SmrtPhone logs daily; pair with IPQS only, skip Telnyx/Nomorobo/Numverify).
Worth opening for: the full status × line-type score table, the 6-step 30-minute Trestle setup, the Number Verifier 7-step 20-minute setup and device-history reading table, relationship phone tags (Daughter/Husband/Son/Wife/Grandchild/Relative/Spanish Speaking), the full Phone Analysis Report Drive link.

### [text-touch-builder](text-touch-builder.md)
Pre-call SMS warming: four short texts per record stored in four custom fields (Text Touch 1–4), each sent right before the matching call attempt — never instead of the call. Jobs: T1 identity check, T2 the drip ("not sure my text went through"), T3 soft ask (first selling mention, no price), T4 breakup. The SiftStack text-touch-builder skill ships 25 handwritten variants (7 for touch 1, 6 each for 2–4, incl. no-name versions for entities/trusts/initials-only owners), seeded from the record's address + owner so neighbors never get matching sequences and re-runs are deterministic. Rules: <160 characters target (hard cap 320), merge exactly four values (first name, street line only, city, caller's real first name), always end on a one-word question, never name the list, no links/images/prices/emoji. Machine-tell blocklist the skill enforces (refuses, not warns): em/en dashes, semicolons, script phrases, "delve/leverage/utilize"-class vocabulary. Two build paths: manual (create 4 Text custom fields in Misc. group → export the Ready to Call preset → write messages → re-import to the *existing list* so it upserts by address, custom fields never auto-map) or Claude over the API. API gotchas documented with runnable scripts (`create_text_touch_fields.py`, `write_text_touches.py`): custom-field routes need a minted user JWT (Open API key 404s — the routes are absent from its 93-route surface), JWT lasts ~48h but re-mint every 30 min, property search is POST with `x-http-method-override: GET`, values go in via PATCH with field-UUID/value pairs, single-thread at ~2 req/s (6 threads at ~7 req/s got 429 on 529 of 740 records), `group_id` required on create but not returned by the field list. Run rhythm: send touch, then dial, one touch per contact day; a reply stops the sequence (three questions, then push for the call). Compliance: own business number, one-to-one, quiet hours 8am–9pm recipient-local, TCPA + state law on you.
Worth opening for: all sample variants with character counts, the name-hygiene table (C Eugene Suthard → "Eugene"; trusts → no-name), the reply-handling table (STOP → DNC immediately, no reply), the copy-paste Claude prompt and follow-up asks, the four quiet-failure traps table.

## How the set fits together

Day 2 is the marketing-execution layer on top of Day 1's data strategy. Niche and bulk are two lenses on one preset machine (folders 01–10, two shared counters); Direct Mail Mastery supplies the piece anatomy and pricing both mail rotations reference; Phone Scoring gates every dial queue (score → tag → load, three protection layers); Text Touch Builder rides the niche call cadence; Team Structure names who runs each piece daily (Data Manager owns Trestle + Sift Mail, Caller owns the dials, at the fixed ratios). Constants held consistent across all six guides: touch costs (call $0.03–0.06, SMS $0.01, mail $0.50–2.00, DP $1.50–4.00), the 5 dial tiers (81–100/61–80/41–60/21–40/0–20), not-interested timers (15/45/90 days), 20–30% of deals from not-interested follow-up, 150+ dials/day, and the never-repeat-a-mailer-type rotation (980K-mailer dataset).
